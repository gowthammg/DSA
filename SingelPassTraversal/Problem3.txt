Given an array where each element represents a stock price on a particular day, find the maximum profit possible from one purchase followed by one sale. You must buy before you sell. If no profit is possible, return 0.
Input: prices = [7, 1, 5, 3, 6, 4]
Output: 5
	import java.util.*;
public class Main {
    public static void main(String[] args) {
      int[] arr = new int[]{7, 1, 5, 3, 6, 4};
      int min = 0;
      int diff = 0;
      for (int i = 1; i<arr.length; i++){
          if (diff < (arr[i]-arr[min]) && min < i){
            diff = arr[i]-arr[min];
          }
          if (arr[min] > arr[i]){
            min = i;
          }
          System.out.println(min+" "+diff);
      }
      System.out.println(diff);
    }
}

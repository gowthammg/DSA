Given an array of integers, find the first index where the sum of all elements to the left equals the sum of all elements to the right. The element at the index itself is excluded from both sums. If no equilibrium index exists, return -1.
Input: arr = [1, 3, 5, 2, 2]
Output: 2
	import java.util.*;
public class Main {
    public static void main(String[] args) {
      int[] arr = new int[]{0,0,0,0,1,0};
      int totalsum = 0;
      for (int i = 0; i<arr.length; i++){
        totalsum += arr[i];
      }
      int output = -1;
      int leftsum = 0;
      for (int i = 0; i<arr.length; i++){
        totalsum -= arr[i];
        if (leftsum == totalsum){
          output = i;
          break;
        }
        leftsum += arr[i];
      }
      System.out.println(output);
    }
}
